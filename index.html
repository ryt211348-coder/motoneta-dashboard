海外ショート ディレクターツール

🅐 台本づくり(誰でも・ブラウザとClaudeだけ)
1. ネタを選ぶ — 「🎯動画ピッカー」を開く。並んでいるのは海外の元動画(日本で需要が証明済みの供給元だけ)。ジャンルで絞って、良さそうな動画の ✓ を押して着手宣言(全員に共有され、被りを防げます)
1.5 企画力(×倍率)と言語 — 再生数の下の ×N は再生数 ÷ そのチャンネルの登録者数。登録者の何倍回ったか＝企画そのものの強さで、×3以上(赤)が狙い目・×1未満はファン視聴の疑い(その人が出ているから見られただけ＝日本語化しても効きにくい)。既定の「企画力順」は倍率が高い順、引用元ランキングの企画力列は「そのchの素材の中央値×倍率／×3以上が何本あるか」で、強い企画を量産しているchほど上に来ます。検索窓の右の言語セレクタで英語だけ/言語別に絞れます(既定=英語。EN?は素材タイトル未収集で名前から推定したもの)
2. 解析する — その行の 🎬 を押す、またはリストに無い動画はURLを工房の欄に貼るだけ。解析・サムネ取得・文字起こしの自動取得が全部同時に始まります
3. 文字起こしは自動で入る — 30秒〜2分で下の欄に自動で入ります(何もしなくてOK)。「自動取得できませんでした」と出た時だけ「📺文字起こしを開く」→ 拡張機能「YouTube Summary」のCopy transcript → このタブに戻る(自動取り込み)。※自動取得はチームの「ワーカーPC」が担当します。Windowsで担当してくれる人はワーカーをダウンロード(中のREADMEどおりstart.batを起動しておくだけ・誰か1人でOK)。Instagramのリール・TikTok・X(旧Twitter)の動画も解析欄にURLを貼ればOK(IG 2026-08-06〜 / TikTok・X 2026-08-10〜)。文字起こしはどれも自動で入ります(30秒〜2分。音声をDL→Whisperで文字起こし)。IGで入らなかった時だけ予備の「📸 IG文字起こしサイトを開く(無料・ログイン不要)」→ サイトにURLを貼り付け → 文字起こし → コピー → このタブに戻ると自動で入ります
4. 台本を作る — ①「📋 Claude用プロンプトをコピー」→Claudeに貼る(プロンプト＋文字起こし)。②「🖼 サムネをコピー」→もう1回貼る(サムネ画像が付く)。この2セットで送信準備完了。対話モードON(推奨)なら、まずサムネ言語化・全文和訳(話者ラベル付き)・展開マップ(起承転結)とAIのセンターピン仮説が出て「あなたのセンターピンは? 他に伸びた要素は?」と聞かれるので、自分の読みを返して(OKだけでも可)すり合わせてから→冒頭→台本の叩き台(削り候補マーク付き)→サブタイトルA/B案(後付け)・使用区間リストへ進みます。叩き台は字数で縛りません(2026-08-06変更)。元素材の尺に応じて長くなるのが正常で、文字起こしの流れに沿って展開をほぼ削らない「長いあらすじ」を先に書き切り、そこから縮めるのがライターの腕の見せ所(シーンを削る。1シーンを膨らませない)。さらに2026-08-06、字数指定を完全に撤去して「構造で長さを担保する」方式に変えました: AIは①シーン見出しの数だけブロックを書く ②各ブロックに元動画の秒[m:ss-m:ss]を併記して時間軸に穴が無いか自己検査する(3-c照合表・6-c穴チェック)。対話モードは「読むターン(和訳・見出し)→書くターン(叩き台)→サブタイ」の3ターンに分かれ、叩き台が途中で切れたら「続けて」と言えば続きが出ます(短く畳むことは禁止してあります)。海外の固有名詞は日本人向けに言い換わります(ムース→ヘラジカ／マイル→km／華氏→摂氏／sheriff→保安官／覚えられない人名は「運転手の男」等の役割に)。和訳の最後に【言い換えリスト】(原語→台本で使う日本語)が出るので、意味が変わっていないかはそこで確認してください。縮め方は工房プロンプト内の「叩き台の書き方」章に全部書いてあります。訴求はA案(センターピン直球)から選ぶのが基本。「📖 映像タイムライン」ボタンが出る素材は、画像を貼る必要はありません(2026-08-06)。各コマに何が写っているかを秒ごとに読み取り、その秒のセリフと突き合わせた一覧がプロンプトに自動で入ります。台本が文字起こしだけから作られて映像とズレる問題への対処です。ボタンが出ない素材は従来どおり、セリフがほぼ無いなら「🎞ストーリーボード画像」を、「🎞1秒コマ(密)」が出るなら密シートを全部Claudeへ貼る。60秒台本は映像照合前の叩き台なので、そのまま使わず映像と照らしてセリフ・時刻を確定させる
5. 編集者に渡す場合 — ②の欄に最終台本を貼って「📋 編集指示書プロンプトをコピー」→ Claudeに貼ると、詳細タイムスタンプ付き文字起こし＋台本1行ごとの「元動画のどこ(何秒-何秒)を切るか」対応表が出るので、そのまま編集者へ。URL解析済みなら台本を貼るだけでOK。自分で動画まで仕上げる場合は下の🅑へ
5.5 台本が完成したら③に登録 — 工房の「③初稿と完成形を登録」に、最初の台本(初稿)とフィードバック反映後の完成形を貼って送信するだけ。あなたの直しがAIのノウハウになり、次からの叩き台の精度が上がります。余裕があれば「差分分析プロンプト」も自分のClaudeで回すと、なぜ直されたかの言語化が自分のスキルにもなります
5+. 素材動画のダウンロード — プレイヤーの「⬇素材DL」でURLがコピーされ、MediaHuman YouTube Downloaderが起動していれば自動で追加されます。⚠️全部mp3(音声だけ)になる場合はMediaHumanの環境設定で「形式」がMP3になっているのが原因。「オリジナル」または「MP4」・品質=最高に設定してください
🅑 カット位置を決める(📝台本シート)
6. カット位置を入れる — プレイヤー下の「📝台本シート」にスプシのB列(台本)を貼り付けると疑似スプシになります。カット位置セルを選んで「⏱ 現在秒を選択セルへ」を押すとその瞬間の秒数が入って選択が次の行へ進みます(行を飛ばすのも自由)。位置合わせは大きいシークバーと「⏪5秒/◀1秒/⏯/1秒▶/5秒⏩」。間違えても⌘Z/Ctrl+Zでひとつ前に戻せます。終わったら「📋カット位置列コピー」→ 空行も空のままコピーされるので、スプシのC列の先頭セルに貼るだけで行ズレしません
6+. ✂IN/OUT区間登録 — 右のプレイヤーで再生しながら「✂IN」を押すとその瞬間がカット開始点として登録されます(INだけでOK・複数可)。区間にしたい時は続けて「→OUT」。▶で頭出し、✕で削除。スプシのカット位置列には「📋INだけコピー」(13:09〜形式・1行=1セル)、Premiere書き出し用には「📋カット表コピー」(IN→OUTの区間のみ)。
7. テロップ台本を入れる — 「📝テロップ編集」を開き、Claudeが出した台本を1行=1テロップで入力。行の種類は各行のチップで切替: タイトル(全編表示)・ナレ(白・めたんが読む)・緑(めたんが読む)・素材(素材セリフ=ナレ無し・素材音声100%でテロップだけ出す)・間(ナレ無しで聞かせる秒数)。ナレ行の🔉スライダー=そのナレ中の素材音量(ダッキング量)。SE行=効果音(名前を候補から選ぶ・⏱で鳴らす時刻・A3に配置)。コマ送りがある動画は「🎬シーン切替」の時刻チップからSE行をワンタップ追加。スプシに台本がある場合はA〜C列(種別・セリフ・素材時刻)をコピーして「📥スプシ取り込み」で一括変換(C列の時刻は@アンカーとして自動付与)。テキスト選択→「《大きく》」で部分強調、Enterキーでそのまま改行。プレビューはテロップを上下ドラッグで位置調整・ダブルクリックで該当行へ。タイトル/緑セリフの色はカラーピッカー、タイトル黒背景(全幅帯=映像に隠れない黒帯/OFFで角丸ピル)・タイトル2行目サイズ・行間・《》倍率・セリフ影(ぼかし/ふくらみ)もスライダーで変更可(標準はチームテンプレ準拠)。《1.2:文字》のように数字を書くとその文字だけ任意倍率。「📱UIかぶり」でショートUIとの重なりを確認
8. ナレのタイミング合わせ — 素材のセリフ(叫び声・会話など)の頭で動画を一時停止 → その直前に言い終わってほしいセリフ行をクリック → 「⏱ここまでに言い終わる」。行頭に@時刻が付き、ナレが自動で逆算配置されます
9. デモ再生で確認 — 「▶デモ再生」で、めたんナレ+カット+テロップ+SEを本番とほぼ同じ状態で試聴(ナレ中は素材音声が🔉の値まで自動で小さくなります)。SEの音はSEライブラリのあるMacでのみ鳴ります(python3 scripts/se_server.py・make_edit.py実行時は自動起動)。※要VOICEVOX: Macのターミナルで tools/macos-arm64/run --cors_policy_mode all を起動しておく(「address already in use」と出たら既に起動済みなのでそのままでOK。無いPCはこのステップを飛ばしてOK)
10. Premiere用に書き出す(Macの管理者) — 「📋カット表コピー」した状態で、テロップ編集の「📋台本をコピー」→ 台本.txtに保存 → ターミナルで python3 scripts/make_edit.py -s 台本.txt → デスクトップの「元ネタ編集」フォルダにXML一式が生成 → Premiereで「ファイル→読み込み」でほぼ完成形(V1素材/V2セリフ/V3タイトル/A1素材音声/A2めたんナレ)。A1にはナレ中のダッキング(音量バーの値)とカット点の30msフェードが音量キーフレームで焼き込み済み。素材セリフの時刻一覧「素材セリフ.txt」も自動生成されるので@アンカーの下調べにも使えます
 ※データは毎晩自動更新。引用元を自分で探す場合は「📊引用元ランキング」から
この工房は独立した4つの道具です。動画1本につき1ページではありません（下に全部並んでいて、いつでも使えます）
①素材を解析 → 台本プロンプト＝素材ごと ／ ②完成台本 → 編集指示書＝素材ごと ／ ③初稿と完成形を登録＝素材と無関係・いつでも ／ ④投稿後の理由を書く＝結果が出た分だけ自動で並ぶ
別の動画をやるときは、①のURL欄を貼り替えるだけです（②③④はそのまま使えます）
① 元動画URL → Claude用台本プロンプトを生成
①参考動画（競合が伸ばした切り抜き）のURLから元素材（一次情報の生映像）を特定 → ②元素材を上の「解析」欄で解析 → ③参考動画の文字起こしを下に貼る → 参考動画の構成をそのまま踏襲した"上位互換"プロンプトが出ます。参考動画の勝ち筋（展開の順番・山の位置）は維持し、元素材から情報を足して尺・情報量・分かりやすさで上回るのが狙いです。
元素材＝上の「解析」欄で解析した動画（文字起こし・盛り上がり・コマ送りを使用）／参考動画＝ここに貼った構成の見本。両方の文字起こしをAIが照合して、参考動画の構成のまま上位互換を作ります。コマ送り画像（🎞1秒コマ）も一緒に貼ると照合精度が上がります。
🎞 ストーリーボード画像を保存 — セリフが無い(ノンバーバル)素材は、この画像もプロンプトと一緒にClaudeへ貼ると映像を読み取って台本を作れます

まず📋を押してClaudeに貼る(本文) → 次に🖼サムネをコピーを押してもう1回貼る(画像)で送信準備完了。対話モードON: 1つ目・読むターン=サムネ言語化・全文和訳(＋【言い換えリスト】)・展開マップ・シーン見出しの一覧・AIのセンターピン仮説が出て「あなたのセンターピンは?見出しに抜けは?」と聞かれます → あなたの読みを返す(OKだけでも可) → 2つ目・書くターン=叩き台をまとめて出す(長くなるのが正常。途中で切れたら「続けて」) → 3つ目・サブタイA/B案。OFF: 従来どおり一気に出力。叩き台の字数指定は使いません。長さはシーン見出しの数で決まり、AIが見出し↔叩き台の対応表と元動画の秒の穴チェックを自分で回します。海外の固有名詞も日本人向けに言い換わります(ムース→ヘラジカ／マイル→km／人名→役割)
② 台本が完成したら → どこを切るかの指示書(行ごと対応表)
Claudeに貼ると、台本1行ごとに「元動画のこの区間(何秒-何秒)が合う」の対応表と1〜4秒粒度の詳細タイムスタンプ文字起こし(和訳付き)がタブ区切り=スプシにそのまま貼れる形で出ます。①でURLを解析済みなら台本を貼るだけ=URL＋完成台本で「どこを切るか」が一発で分かる(出力をコピー→スプシのA1に貼り付け→そのまま編集者へ)
③ 初稿と完成形(FB反映後)を登録 → AIが賢くなる
あなたの初稿と、フィードバックを経た完成形を登録するだけでOK。夜間に差分がノウハウ化され、次からの台本プロンプトに反映されます。
④ 投稿後の結果に「なぜそうなったか」を添える
③で登録した台本のうち、投稿1週間後に結果が出たものです。伸びた台本は「何が良かったか」＝勝ち型、伸び悩んだ台本は「なぜ伸びなかったか」＝避けるべき型として、書いた分だけAIに反映されます（空欄は反映されません）。
各行の頭にある名前は③でその台本を登録した人です。チーム全員分がここに並ぶので、自分の名前の行だけ書けばOK（自分の行が上に来ます）。
探す前にこの2つを使ってください
①上の「尺」チップで先に切る。長い素材は台本の工数が跳ね上がります。〜1分＝既にバズった海外ショートそのもの（日本語化するだけなので一番速い・在庫が一番多い）、〜3分＝短めの長尺（凝縮しても展開が落ちにくい）
②再生数の下の ×N＝再生数 ÷ そのchの登録者数＝企画そのものの強さ。×3以上(赤)が狙い目・×1未満はファン視聴の疑い。既定の並びは この×N順 です（拡張機能を入れなくてもここで見られます）
